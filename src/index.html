DAILY-Funktionen auf Vercel: Kurse, Fußballdaten, Abfahrten, Schulferien, Wetterwarnungen, Tankpreise und „An diesem Tag“ werden über eigene Funktionen auf dem Server abgerufen. Die Anbieter dieser Daten sehen dabei nicht deine IP-Adresse. Für Warnungen und Tankpreise wird nur der auf etwa 1 km gerundete Standort deines gewählten Orts übermittelt. DAILY braucht kein Konto und verarbeitet außer dem Ort keine persönlichen Daten.

Schriftarten werden direkt von diesem Server geladen, nicht von Google.
