# DAILY – Logo (seit 0.53.1, 03.10.2026)

Abreißblatt mit rotem Kopf, Lochung, umgeknickter Ecke und einer kleinen Liste mit Häkchen (Mitmachen). Farben aus der App:
Grund `#2F3A35`, Papier `#F7F2E8`, Rot `#B8322A`, Tinte `#1F2522`, dahinterliegendes Blatt `#C9BFAB`, Ecke `#DDD5C4`.

| Datei | Wofür |
|---|---|
| `daily-logo.svg` | Logo mit dunkelgrünem Grund (quadratisch) – gleich wie `src/icon.svg`, aus dem der Build alle App-Symbole erzeugt |
| `daily-logo-rund.svg`, `daily-logo-rund-1024.png` | dasselbe mit runden Ecken (z. B. für Präsentationen) |
| `daily-logo-frei.svg` | freigestellt ohne Grund (Lochung im roten Kopf) – für helle oder farbige Flächen |
| `daily-logo-1024.png`, `daily-logo-2048.png` | Logo mit Grund als Bild |
| `daily-logo-frei-1024.png`, `daily-logo-frei-2048.png` | freigestellt, durchsichtiger Hintergrund |

SVG-Dateien lassen sich beliebig vergrößern. Eigene, einfache Formen – keine fremden Bildrechte.
